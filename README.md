# Clone3X-ui
Script to cloning working 3X-ui server's settings to new host 

To run:

```bash
curl -fsSL https://raw.githubusercontent.com/PavelDobre/Clone3X-ui/main/main.sh -o main.sh
chmod +x main.sh
sudo ./main.sh
```
OR:

```bash
curl -fsSL https://raw.githubusercontent.com/PavelDobre/Clone3X-ui/main/main.sh -o main.sh && chmod +x main.sh && sudo ./main.sh

```
